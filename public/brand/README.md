# Vensight Mark

Approved identity: white Geist semibold V on UKO blue #2940D3, paired with the Geist wordmark.

- UI mark: 41px square, 8px radius, 28px V, exported at 3x as `vensight-mark-blue.png`.
- Browser favicon: `favicon-32.png` and `/favicon.ico` (16, 32, and 48px PNG frames).
- Typeface license: `/fonts/geist/OFL.txt`.

Assets were rendered from the approved HTML/CSS proposal using the bundled Geist font, not a substituted typeface.
